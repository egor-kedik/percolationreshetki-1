## Запуск

Откройте `index.html` в браузере. Современные браузеры поддерживают ES modules.

Если браузер ограничивает `file://` для модулей, запустите простой локальный сервер:

```bash
python -m http.server 8000
```

После этого откройте `http://localhost:8000/`.

## Функциональность

- генерация случайной квадратной решётки;
- поиск кластеров и сквозного кластера;
- изменение `p` и размера `L`;
- анимация пошагового обхода уже сформированных компонент (не динамика физического роста);
- фильтр сквозного кластера;
- экспорт визуализации в PNG;
- синхронизация `p` и `L` с URL;
- построение вероятности вертикального пересечения `R_L(p)` с 95% доверительным интервалом;
- аккордеоны на страницах теории и применений;
- открытие раздела теории по hash URL.

Логика исходных HTML вынесена в ES-модули без подключения сторонних библиотек.

## Запуск проекта

Откройте папку проекта в VS Code и запустите `index.html` через расширение Live Server (кнопка **Go Live**). Не открывайте HTML двойным щелчком: основной вариант использует JavaScript-модули (`type="module"`), которые могут блокироваться при запуске через `file://`.

Размер решётки ограничен значениями 10, 20 и 30; максимальный размер — **30 × 30**.


## Научные оговорки в численных результатах

- График показывает `R_L(p) = P(вертикальное пересечение)` для конечного размера `L`, а не параметр порядка `P∞`. Заштрихована 95% биномиальная доверительная область Уилсона.
- Для квадратной 2D-решётки `p_c ≈ 0.592746` показывается как справочное теоретическое значение, а не результат шумной бисекции.
- Таблица теории использует `β(2D) = 5/36 ≈ 0.1389`.
- Анимация — визуализация обхода заранее сгенерированных компонент; это не физическая временная модель.
- `PercolationViewModel` содержит команды и presentation state между моделью и контроллером представления.
